# ChipDocs KiCad 7/8/9 Action Plugin (`org.chipdocs.kicad`)

Search **7,900+ verified electronic components** from **[chipdocs.org](https://chipdocs.org)** directly inside KiCad PCB Editor and install synchronized **`.kicad_mod` IPC-7351B footprints**, **`.kicad_sym` IEEE-315 symbols**, and **3D `.step` AP214 models** into your active project folder with 1 click.

## Installation
1. Download **`org.chipdocs.kicad-1.0.0.zip`** from [Releases](https://github.com/chipdocs/chipdocs-kicad-plugin/releases/latest).
2. Open **KiCad → Plugin and Content Manager → Install from File...** → select the `.zip` archive.
3. Open **PCB Editor** → click **ChipDocs Library Downloader** in the toolbar.
